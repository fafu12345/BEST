# 건물별 호실 기본정보

매물 등록·수정 화면에서 상가 또는 사무실을 선택하고, 건물명 `행운빌딩` 또는 `한솔프라자`를 선택합니다. 보기에 없으면 같은 이름으로 `보기 추가`를 한 번 사용합니다.

호실을 입력한 뒤 다른 입력란으로 이동하면 전용면적(㎡)과 층수를 채웁니다. 자동 입력한 값은 직접 수정할 수 있습니다. 기본정보는 실제 매물을 생성하지 않으며 DB 업데이트 없이 코드와 함께 배포됩니다.

- 행운빌딩 21호실, 한솔프라자 45호실.
- 호실 숫자로 층수를 추정합니다. `205-A`, `206-B`는 2층, `303-1`은 3층입니다.
- `중101`~`중104`는 호실명을 보존하며 사용자 확인에 따라 1층입니다.
- 한솔프라자 `205`, `206`의 면적은 미입력으로 두었습니다. `205-A/B`, `206-A/B`와 별도 호실입니다.
- 한솔프라자 `501`은 제공된 값 그대로 1169.14㎡입니다.
- 건물 총층수는 추정하지 않습니다.
- `등록된 호실 정보 불러오기`는 기존 사무소 매물 이력을 우선 확인하고, 이력이 없으면 기본정보를 사용합니다.
