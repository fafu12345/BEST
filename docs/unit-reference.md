# 건물별 호실 기본정보

매물 등록·수정 화면에서 상가 또는 사무실을 선택하고, 건물명 `행운빌딩` 또는 `한솔프라자`, `평촌빌딩`, `주공공이`, `아이파크상가`, `신세대상가`, `삼일프라자`, `씨티빌딩`, `벌말프라자`, `부림프라자`, `무지개상가`, `동아프라자`를 선택합니다. 보기에 없으면 같은 이름으로 `보기 추가`를 한 번 사용합니다.

호실을 입력한 뒤 다른 입력란으로 이동하면 전용면적(㎡)과 층수를 채웁니다. 자동 입력한 값은 직접 수정할 수 있습니다. 기본정보는 실제 매물을 생성하지 않으며 DB 업데이트 없이 코드와 함께 배포됩니다.

- 행운빌딩 21호실, 한솔프라자 45호실, 평촌빌딩 25호실, 주공공이 63개 항목, 아이파크상가 31개 항목, 신세대상가 43호실, 삼일프라자 63개 항목, 씨티빌딩 12호실, 벌말프라자 28호실, 부림프라자 36개 항목, 무지개상가 38호실, 동아프라자 47개 항목.
- 호실 숫자로 층수를 추정합니다. `205-A`, `206-B`는 2층, `303-1`은 3층입니다.
- `중101`~`중104`는 호실명을 보존하며 사용자 확인에 따라 1층입니다.
- 한솔프라자 `205`, `206`의 면적은 미입력으로 두었습니다. `205-A/B`, `206-A/B`와 별도 호실입니다.
- 한솔프라자 `501`은 제공된 값 그대로 1169.14㎡입니다.
- 건물 총층수는 추정하지 않습니다.
- `등록된 호실 정보 불러오기`는 기존 사무소 매물 이력을 우선 확인하고, 이력이 없으면 기본정보를 사용합니다.

자료: `src/lib/properties/unit-reference.ts`
검증: `node scripts/test-unit-reference.mjs`

## 평 단위 및 묶음 호실

주공공이는 제공된 면적을 평 단위 원본으로 보존하며, 해당 건물 등록·수정 화면의 면적 입력란도 평 단위로 표시합니다. 저장·검색은 기존 구조와 동일하게 ㎡로 환산합니다(1평 = 3.305785㎡, ㎡ 소수점 둘째 자리 반올림). 다른 건물은 기존처럼 ㎡로 입력합니다.

`120~121`, `110-3~110-4`, `103~104`, `209~210` 등은 제공된 묶음 그대로 하나의 항목이며, 개별 호실로 나누거나 면적을 분배하지 않습니다. 호실의 물결표 앞뒤 공백은 무시합니다.

주공공이 138·140·214호와 아이파크상가 102호는 면적 미입력입니다. 원본에 없는 호실은 추가하지 않았습니다.

벌말프라자 201호 원본은 61.875㎡로 보존합니다. 기존 DB의 면적 저장 단위(소수점 둘째 자리)에 맞춰 불러오는 값은 61.88㎡이며, 입력 화면에서 원본과 반올림 내용을 안내합니다. DB 구조 변경은 필요 없습니다.

부림프라자 역시 소수점 셋째 자리 원본을 보존합니다. 예: 101호 51.975㎡ → 입력 51.98㎡, 208호 104.525㎡ → 입력 104.53㎡, 506호 138.275㎡ → 입력 138.28㎡. 306-1호(95㎡)와 306호(60㎡)는 별도 항목입니다.

동아프라자의 105~106, 116~117, 125~126, 135~136은 각각 하나의 묶음 항목입니다. 204·208호는 면적 미입력입니다.
